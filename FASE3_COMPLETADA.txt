Presentation Layer → Domain Layer → Data Layer

1. UI llama a UseCase.invoke()
2. UseCase obtiene ubicación de LocationDataSource
3. UseCase llama a Repository.getNearbyBirds(lat, lng)
4. Repository llama a NetworkDataSource.getBirdsNearby()
5. NetworkDataSource hace HTTP request a Xeno-canto API
6. Repository mapea DTOs a modelos de dominio
7. Resultado fluye de vuelta a UI
