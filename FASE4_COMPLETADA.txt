FLUJO COMPLETO DE LA APLICACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. MainActivity lanza BirdScreen con BirdViewModel
2. BirdScreen ejecuta LaunchedEffect → viewModel.fetchBirds()
3. ViewModel llama getNearbyBirdsUseCase.invoke()
4. UseCase obtiene ubicación de LocationDataSource
5. UseCase llama Repository.getNearbyBirds(lat, lng)
6. Repository llama NetworkDataSource.getBirdsNearby()
7. NetworkDataSource hace HTTP GET a Xeno-canto API
8. Repository mapea DTOs a modelos Bird
9. ViewModel actualiza uiState a Success(birds)
10. BirdScreen muestra LazyColumn con Cards
11. Usuario presiona Play → AudioPlayerHelper.playAudio(url)
12. MediaPlayer reproduce audio de ave
